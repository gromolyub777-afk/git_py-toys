# git_py-toys

## Git Committer (`git_committer.py`)

Простое GUI-приложение (Tkinter), которое **коммитит изменения из указанной папки
в выбранный git-репозиторий** по нажатию одной большой кнопки.

### Запуск

```bash
python git_committer.py
```

Зависимости: только стандартная библиотека Python (tkinter) и установленный `git`.
На Linux при отсутствии Tk: `sudo apt install python3-tk` (или `pacman -S tk`).

### Как пользоваться

1. Запустите приложение — файл `config.json` создастся сам, ничего настраивать не нужно.
2. Укажите **только два поля**:
   * **Папка** — откуда коммитить (кнопка «…» рядом открывает выбор папки);
   * **Репозиторий** — путь к локальному git-репозиторию **или** URL (`https://…`, `git@…`, путь, оканчивающийся на `.git`).
3. Нажмите большую зелёную кнопку **КОММИТ**.
4. Маленькая кнопка **«...»** справа внизу открывает файл `config.json` в системном редакторе.

Оба пути сохраняются в конфиге — при следующем запуске достаточно просто нажать «КОММИТ».

### Что делает кнопка КОММИТ

* если репозиторий задан URL — клонирует/обновляет его в подпапку `repo_<id>`;
* синхронизирует содержимое папки-источника в рабочую копию репозитория;
* выполняет `git add -A` и `git commit` (с автором и сообщением из конфига);
* при `"push": true` — пушит в `origin`;
* пишет историю удачных коммитов обратно в `config.json`.

### Структура config.json (генерируется автоматически)

```json
{
  "source_folder": "/путь/к/папке/откуда/коммитим",
  "repository": "/путь/к/репозиторию или https://github.com/user/repo.git",
  "branch": "main",
  "commit_message": "Автокоммит: {datetime}",
  "author_name": "Git Committer",
  "author_email": "committer@local",
  "push": false,
  "history": []
}
```

Необязательные ключи (`branch`, `commit_message`, `author_*`, `push`) можно править
в конфиге через кнопку «...», но для работы достаточно указать лишь папку и репозиторий.
